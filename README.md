# 图迹 0.3.3 使用说明

Android 10+，原生 Android Java，包名 io.tuji.app，versionCode 7。与此前版本使用同一发布签名，可直接覆盖安装，请勿先卸载。

## 全屏看图和坐标复制

点击照片主体进入黑色全屏查看器。单击显隐控件，双击在适屏与约2.5倍之间切换；双指可缩放到适屏8倍，放大后单指拖动。图片按授权URI读取，未允许GPS权限仍能看图。先加载受限底图，再按需读取可见区域高清分块；格式不支持或解码失败时回退采样预览，显示相应说明。

点击底部“照片信息”展开时间、定位状态、小地图和导航。展开面板可滚动，高度不超过可用区域七成。返回键先收起信息，再退出看图；关闭按钮直接退出。横竖屏切换保留照片、相对适屏倍率、图片中心和面板状态。

坐标标为原始WGS84，显示十位小数。点击复制纬度、复制经度或复制坐标对；整对格式如30.5126304444,114.3313751111，纬度在前，英文逗号分隔，不加标签。没有有效定位、权限不足或尚未解析时禁用复制，不能复制旧值。腾讯显示使用派生坐标，不改变原件或复制内容。导航可选高德／百度，未安装时提示。

## 图库、选择与教程

默认进入照片页。允许全部图片后直接浏览MediaStore已索引照片，无需导入；部分授权只显示可访问照片。私密空间、未下载的云端图片和其他应用未公开的文件不在本机图库范围内。

双指捏合调整三至六列；点右上小选框切换选择，点主体看详情。日期旁全选／取消仅针对当前相簿与筛选中的当天照片。长按滑动选中起点到终点的完整区间，回拖缩短，保留手势前已选；边缘自动滚动，右侧独立通道按日期快滑。已选可跨相簿保留、预览、移除和清空。

接收右侧新增教程。八个离线图文主题包含快速上手、照片与GPS权限、区间选择、手机／电脑收发、时间包名与ZIP、看图复制导航、缓存与原件删除及常见问题。每章有内置矢量示意步骤和对应操作入口，不使用私人照片或在线视频。拒绝图片权限后仍能阅读；章节内返回回目录，保存章节和阅读位置。

## 局域网收发

双方连接同一Wi-Fi或热点。选择照片后到发送页，点击设备并确认；也可用加号输入设备IP。电脑接收端可使用LocalSend。首次接收默认手动确认，可主动长期信任真实HTTPS证书，在设置中撤销。

照片生成 .tuji.zip，按发起发送时手机本地时间命名，如202612120531.tuji.zip，同分钟后续加_2、_3。包内图片平铺，不含编号子目录或可见清单；Windows解压位置由电脑用户选择。图迹兼容ZIP v1/v2；原版LocalSend按普通ZIP接收。普通文件保留原名，不额外打ZIP。照片按原始字节发送，包含实况附加数据，当前查看器显示静态画面。

接收端先校验路径、大小和全部哈希，再保存至系统“图迹”相簿，重复原件按哈希去重。删除照片会明确请求删除系统原件，取消或失败保留记录。应用打开时可接收新任务；已开始任务使用前台服务，闲置后台不保证接收，厂商省电策略仍需真机确认。

## 空间与隐私配置

照片发送使用原件快照＋ZIP，额外峰值约两倍原件总大小。成功、失败或取消后检查清理；强杀残留在下次启动恢复。设置可查看总／活动／闲置任务缓存，仅清理闲置，保护进行中的任务，不处理相册、下载原件、索引或地图缓存。

定位缓存为私有 SQLite gallery.db，存URI、文件变化标识、解析状态、经纬度，不含照片副本；一万条代表记录估算约2.1MB。图库24MiB缩略图缓存属于内存，与任务磁盘缓存不同。

## 源码构建

使用JDK21、Gradle8.13、Android SDK36及build-tools36.0.0；无需Flutter、Rust或NDK。参见BUILD.md与TESTING.md，本地填写SDK路径、绑定包名及签名的腾讯Key和签名配置。源码包不含Key、私钥、私人照片或构建产物。自行签名的包不能覆盖本次发布包。
